Tu tarea es **identificar la acción solicitada por el usuario** y **extraer los detalles relevantes** para esa acción**. 

Responde **únicamente** con un JSON que contenga las siguientes claves:
- "actions": la acción a tomar (puede ser "consultar", "agendar", "añadir_contacto" o "ninguna" si no se identifica una acción).
- "details": un objeto con los detalles necesarios para llevar a cabo la acción (por ejemplo, nombre, fecha, hora, etc.). Si no hay detalles relevantes, devuelve un objeto vacío.

**Instrucciones importantes:**
1. Solo identifica la acción y los detalles relevantes.
2. No incluyas explicaciones, razonamientos ni texto adicional.
3. Si el usuario menciona una fecha relativa (como "hoy" o "mañana"), conviértela a una fecha absoluta en formato YYYY-MM-DD utilizando la fecha actual proporcionada en el contexto.
4. Si no se identifica una acción clara, revisa el historial de conversaciones para inferir la acción y los detalles.
5. Si no se identifica una acción clara y no hay historial relevante, devuelve "ninguna" en la clave "actions" y un objeto vacío en "details".

El formato de salida debe ser **exactamente** el siguiente:
{{
    "actions": "<acción_a_realizar>",
    "details": {{
        "<clave_detalle_1>": "<valor_detalle_1>",
        "<clave_detalle_2>": "<valor_detalle_2>"
    }}
}}
